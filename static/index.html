Powerful Capabilities

Engineered for Transparency & Control

SysPulse gives you complete visibility into system resource consumers and hardware wear through four specialized diagnostic modules.

1. Hardware Doctor & Health Grade

Calculates an aggregated health score (0-100) and letter grade (A-D) based on real hardware health metrics.

  • CPU package & ACPI core thermals
  • Battery degradation & cycle count wear
  • Low storage exhaustion warnings
  • Journalctl & Windows Event Log scanner

2. RAM Analytics & Streaming Graph

High-frequency memory profiling with live Chart.js visualizations that track physical allocations over time.

  • Used vs Available RAM streaming timeline
  • Doughnut breakdown (Used, Cached, Buffers, Free)
  • Linux Buffer Cache / Windows Standby memory
  • PSI Memory Pressure stall detection

3. Process Controller & Crossing

Sort tasks by execution state with interactive batch selection and multi-process termination controls.

  • Active (CPU/Terminal/User) vs Background sorting
  • Process Crossing: Mark rogue tasks with red strike-through
  • Kill Crossed (N): Batch-terminate marked PIDs
  • Safety Shield: Protects systemd, Xorg, dwm, and explorer

4. Application Manager

Aggregates memory and threads across multi-process applications (Chrome, VS Code, Discord).

  • Total RSS memory and CPU sum per application
  • Package resolution (APT, Snap, Flatpak, Winget)
  • Dry-run uninstallation simulation preview
  • One-click graceful app termination

Quick Start

Install & Run SysPulse

Launch SysPulse interactively in seconds with your native terminal.

Clone the repository and run the launcher. The script checks Python 3 and installs python3-psutil automatically if missing:

Terminal (Bash) 
# 1. Clone repository
git clone https://github.com/AntonyMN/syspulse.git
cd syspulse

# 2. Launch SysPulse
./start.sh

The web dashboard will start at http://127.0.0.1:5050.

Run the batch launcher in Command Prompt or PowerShell. It verifies Python 3, installs psutil via pip, and opens your default browser:

Command Prompt / PowerShell 
:: 1. Clone repository
git clone https://github.com/AntonyMN/syspulse.git
cd syspulse

:: 2. Launch SysPulse
start.bat

Your default web browser will automatically open http://127.0.0.1:5050.

Permanent Execution

Run as a Background Daemon (Always Active)

Configure SysPulse to start automatically on system boot and run silently in the background without needing an open terminal.

SysPulse includes a one-command systemd installer. It configures a user service with automatic restart on failure and enables user lingering so it boots before GUI login:

Install Systemd Daemon 
# Install and start background daemon
./service/install-service.sh

# Check daemon status
systemctl --user status syspulse.service

# View live systemd logs
journalctl --user -u syspulse.service -f

# Uninstall and stop daemon
./service/uninstall-service.sh

On Windows, SysPulse registers a Scheduled Task triggered at user logon. It uses pythonw.exe (headless Python) so no command prompt window remains visible:

Install Windows Background Task 
:: Run installer (registers SysPulseDaemon via schtasks)
service\install-service.bat

:: Alternatively, run in PowerShell:
powershell -ExecutionPolicy Bypass -File service\install-service.ps1

:: To stop and remove the background task:
service\uninstall-service.bat
Network & Reliability

Port Management & Conflict Safeguards

Running a system daemon continuously occupies a local network port. Here is how SysPulse avoids port conflicts.

Why Port 5050 & How Port Clogging is Prevented
By default, SysPulse binds to port 5050. If another development server (or another instance of SysPulse) is already using port 5050, SysPulse activates its built-in safety mechanisms:

1. Automatic Port Rollover

If 5050 is in use, server.py automatically checks 5051, 5052, up to 5070 until an open port is secured. You never encounter an unhandled EADDRINUSE crash.

2. Custom Port Environment Variable

Specify any desired port directly before launching:
PORT=5055 ./start.sh (Linux)
set PORT=5055 && start.bat (Windows)

3. Finding & Freeing Clogged Ports

Inspect which PID is holding port 5050:
Linux: lsof -i :5050 or fuser -k 5050/tcp
Windows: netstat -ano | findstr :5050

Developers & Automation

REST API Reference

All telemetry and process management actions are exposed through clean JSON endpoints.

Method Endpoint Description
GET /api/system/condition Returns laptop health score, thermals, battery wear, storage, and boot errors.
GET /api/memory/stats Returns physical RAM, swap usage, memory pressure, and 60-second time series.
GET /api/processes?category=active&user=me Returns process list with Active/Background classification and filter queries.
POST /api/processes/kill Terminate a single PID gracefully (SIGTERM) or forcefully (SIGKILL).
POST /api/processes/kill-batch Terminate multiple crossed PIDs in batch ({"pids": [123, 456]}).
POST /api/processes/kill-all-active Mass-terminate all non-protected active user processes with Safety Shield.
GET /api/applications Aggregated metrics across application process trees (Chrome, VS Code).
